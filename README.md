## Overview

Household Management is a The Sims 4 mod that replaces the need to cycle through individual Sims by providing a unified household dashboard panel displaying every family member's need bars, mood, active skill progression, and relationship statuses simultaneously. It integrates seamlessly with the base game and expansion packs, supporting households of up to eight Sims with a clean, scrollable panel.

Whether you're a newcomer just getting started or a seasoned pro looking for advanced tools, **The Sims 4 Household Management** delivers the features you need in a clean, intuitive package.

## Key Features

| Feature | Description |
|---------|-------------|
| **Household Dashboard** | Single panel shows every Sim's needs, mood, and status at once |
| **Skill Overview** | Active skill bars and learning progress for all household Sims |
| **Relationship Panel** | Household-wide relationship status summary with friendship tiers |
| **Task Delegation** | Queue needs-fulfillment actions for multiple Sims simultaneously |
